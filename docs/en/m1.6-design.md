# Outpost M1.6 design: "official" needs the checker's agreement; the brief's wording for paused products

> 2026-11-28. The user asked me to go ahead as I suggested: first fix "official is the agent's own claim" (M1 acceptance item 6) and "a paused product still says it continues tomorrow" (item 11), add two free checks on the real Desktop, then do M2. This document covers those two, plus the repeated rows on the Sources tab, found during the live check and fixed along the way (section 3); the results of the checks are at the end. The approach is my call throughout.

## 1. "Official" needs the checker's agreement

### The problem

Whether a source is 「官方」 (official) used to be up to the researcher alone. Two of Muse's findings once marked muse.ai (another company) and the UK regulator ICO as official. Under §8, "an official source speaking about its own affairs is enough on its own", so such a source could carry a finding into the brief by itself.

### The first plan, and why it was dropped

The first plan was to check sources against the official domain recorded for the product (the suggestion in acceptance item 6). A read-only look at the real data ruled it out:

- **The official domain is itself filled in by an agent when it recommends the product, and can be wrong**: Muse (Meta) is recorded with muse.ai, the very other company. Checking by domain would make muse.ai official.
- **Many genuinely official pages are not under the recorded domain**: Gemini's blog.google and support.google.com, Muse's meta.com and about.fb.com, Cue's help.manus.im, 小艺's Huawei privacy page (dbankcdn.cn), 小豆's App Store page. Checking by domain would demote them all and leave a batch of findings 「待确认」 (unconfirmed) for nothing.
- **Pages under the official domain are not always the company speaking**, such as vivo's forum at bbs.vivo.com.cn.

### What it does now

- The checker already opens every source to see whether the quote is there. Now its report answers one more question, `official`: did this product's maker publish this page? The official site, help centre, official blog or newsroom, its own app-store page and official accounts count; media, reviews, forum posts and other companies (including one with the same name) do not; if it cannot tell, it says so. The official domain is given only as a hint, and the prompt says "it may be wrong; go by the page".
- **Official only when the checker says so**: only then is one source enough, and only then does the interface show 「官方」. Whoever hands a source in (the researcher, or the checker adding a second source) also marks whether it is official; that mark is now only a hint. The checker runs in its own session and opens the page to find the quote, so it is the one that judges who published it.
- When the researcher or a follow-up chat reads the dossier, "official" is also the checker's answer, no longer the mark the source came in with.
- A page that could not be opened cannot show who published it, so the answer is recorded as "cannot tell".
- When the checker does not agree, the finding is treated like anyone else's claim: it needs a second independent source, which the checker looks for as usual (§7.4); without one within 7 days it is 「未证实」 (unproven) and folded away.

### Sources checked before

- Sources checked before M1.6 have no answer from the checker on this, so **none of them counts as official any more**: the interface does not mark them 「官方」, and the type column of the 「来源」 (Sources) tab reads 「官方（未核实）」 (Official (not checked)). They are not judged by domain instead, for the reasons above.
- Findings already decided (verified, unproven, withdrawn) are not judged again. Those still 「待确认」 are handled at the next check as usual.
- For a source handed in with the type 「官方发布」 (Official), the Sources tab's type column now reads one of three things: 「官方发布」 (Official) when the checker agreed, 「不是官方」 (Not official) when it did not, 「官方（未核实）」 (Official (not checked)) when it was never asked. Other types (app store, social account and so on) read as before, with the 「官方」 tag when the checker agreed.

### The cost

- Official pages that will not open (WeChat articles and Zhihu often will not) used to count as verified when the researcher called them official and a search snippet matched the quote; now they count only if the checker can tell from the snippet who published them, and otherwise need a second source. There will be a few more 「待确认」 findings. This is deliberate: slower rather than writing unchecked things into the dossier.
- No extra spending: the checker opens the page anyway and only answers one more question.

## 2. A paused product no longer says "continues tomorrow"

The brief's closing line "the check of X's news ran out of budget; it continues tomorrow" was wrong once X had been paused: it does not run tomorrow. The line now follows the product's current state: for a paused product it reads "X is paused, so it continues once you resume it". After X is resumed, the check after its next daily update takes those findings along.

## 3. The Sources tab lists each page once

An older problem found during the live check: 小豆's 「来源」 (Sources) tab listed 54 rows, but only 21 distinct pages. Each card stores its own copy of what it cites, so one report cited by four cards was stored four times and showed as four identical rows, and the tab's count was inflated with it. Rows are now merged by page (addresses that are the same once written one way: without www., trailing slashes and tracking parameters such as utm_), one row naming every dimension that cites it, and the tab counts pages. Of the copies, the one shown is one the checker found official, else one that was opened.

The same tab had one spot M1.5 missed: in the English interface, the default dimension names in the "cited by" column were still Chinese (定位, 目标人群…); they now follow the language.

## Database

The `sources` table gains a column `official_confirmed` (database version 4); older rows are empty (meaning "never asked").

Going back to 0.1.5 works as for M1.2: first `sqlite3 <data dir>/outpost.sqlite 'PRAGMA user_version=3'`, then install the 0.1.5 package; the older build neither reads nor writes the extra column. **Before installing 0.1.6 again, set it back to 4**, or the column is added a second time and Outpost does not start.

## Version

0.1.6, matching m1.6.

## How it is checked

- Unit tests: when the checker disagrees or cannot tell, a claim about the product itself on one official source is 「待确认 · 只有一个来源」 (unconfirmed, only one source), and verified only when it agrees; sources checked before do not count as official and are not opened again; for a page that could not be opened the answer is recorded as "cannot tell"; leaving the answer out gets the call refused; the database upgrade keeps older sources; the Sources tab's three readings (Chinese and English); the brief's wording for a paused product (Chinese and English).
- On the real Desktop: a real check costs money and was not run. The check after the next daily update is the first to use it: in Runs, open the check session; its `outpost_report_check` calls should carry `official`; afterwards a product's Sources tab shows 「官方发布」 or 「不是官方」 in the type column.

## Worth knowing

- **Muse's recorded official site is muse.ai, another company.** It is now only a hint for the checker and no longer decides what is official, but the researcher sees it too. You can change it to meta.com (or remove it) on Muse's product page, under "⋯ → Edit name and site…". I have not changed it for you.
- After the upgrade, the sources in existing dossiers are no longer marked 「官方」 (old sources are not checked again; that would cost money). New sources are marked once the checker agrees. This follows from "Sources checked before" above; no data is lost.

## Changed after review (2026-11-28)

The independent review found nothing that blocks the release. Changed:

- The first version counted a source as official only when the researcher said so and the checker agreed, but the checker cannot see what the researcher said: for the maker's page the researcher forgot to mark, the checker would agree, take one source as enough and not look for another, while the finding stayed 「待确认」 and was folded away after 7 days. Now the checker's answer alone counts, as the prompt's rule says. For a second source the checker adds itself, it filled in both marks anyway, so this also makes the story consistent.
- When the research and follow-up agents read the dossier, "official" is now the checker's answer (before, it was still the researcher's mark, so a follow-up chat could call muse.ai official).
- The Sources tab's type column reads as described above. New tests: a page the researcher did not mark but the checker agreed to counts as official; a follow-up's first message does not call a source the checker turned down 「官方」; the prompt's `official` line is now covered by a test.

Left: a product only in archived tracks also gets "continues tomorrow", but nothing in the app archives a track now, so it cannot come up. Old sources are not asked again (see above). Going back to 0.1.5 and then to 0.1.6 again needs the database version set (see "Database").
