# 前哨 (Outpost) M1.2 design: adding products to an existing track, moving products between tracks

> 2026-11-26 14:2x the user said: 「the existed track should support add new products, and move the existed products to other track」. To be built after M1.1 is installed in the desktop app. For the main design see [`docs/en/design.md`](design.md), and for M1.1 see [`docs/en/m1.1-design.md`](m1.1-design.md).

## Why

Right now products can be picked only when a track is created. To add a product later, you have to wait for it to turn up in 「候选推荐」 (Candidate recommendations) by chance. A product also cannot be switched from one track to another, for example when 小豆 fits better in 「手机 AI 助理」 (Phone AI assistant).

## The user's decisions

1. **Adding products: both ways are wanted.** Under each track there is a row 「＋ 添加产品」 (+ Add product), and after you click it:
   - If you know the name: fill in the product name (the official site can be left out) and click 「加入并建档」 (Add and build profile);
   - If you want Outpost to search again: write the requirement in one sentence (can be left out) and click 「再推荐一批」 (Recommend another batch). The results go into 「候选推荐」, and you pick from them there as before.
2. **Moving: both 「移到」 (Move to) and 「也加到」 (Also add to) are wanted.** The 「⋯」 (more actions) menu at the top right of the product page has:
   - 「移到其他赛道…」 (Move to another track…): remove it from the original track and put it into the new one;
   - 「也加到其他赛道…」 (Also add to another track…): keep it in both;
   - 「从「X」拿掉」 (Remove from "X"): appears only when the product belongs to two or more tracks.
3. **Rules that do not change:**
   - The product's dossier and history are kept, and only the dimension cards that the new track adds are filled in;
   - A product runs only once a day, no matter how many tracks it is in.

## Approach

### Adding by name (my judgment, can be changed)

1. **First check whether it is already tracked.** Write the name you filled in in the standard form (the M1.1 rule: unify full-width and half-width, ignore case, remove spaces and punctuation), and compare it with the products in other tracks that are tracked, paused or being profiled.
   - **Exactly one match:** add it directly into this track and fill in only the missing cards, at no cost. It shows 「已在「〈赛道〉」跟踪，直接加进来了 · 只补缺的维度」 (Already tracked in "<track>", added directly · only the missing dimensions will be filled in).
2. **No match:** first run a very small 「确认产品」 (Confirm product) task (about ¥0.1–0.2, 1–2 minutes), in which the Agent verifies that the product really exists and belongs to this track, and fills in the company, region, form, official site and icon. If the verification passes, it is added automatically and profile building starts, with the same effect as ticking it in 「候选推荐」 and starting.
   - Why not build directly from the name: the company is half of the basis for deciding that two products are "the same product", and the official site and icon also have to be filled in through this step.
3. **The verification does not pass:** when the product does not exist, has been discontinued, or does not belong to this track, it is not added, and the reason given by the Agent is shown as it is, for example 「没加进来：找不到叫这个名字的产品」 (Not added: cannot find a product with this name).
4. **The result of 「确认产品」 does not go into 「候选推荐」:** it does not count as a batch of recommendations, so it will not push out the batch of candidates you are picking from.

### Recommend another batch

- It uses the existing recommendation task, plus the one-sentence requirement you wrote.
- At recommendation time the Agent already knows which products are tracked. Those already tracked in this track will not be recommended again. Those tracked in other tracks (from M1.1) can still be recommended, with the name and company copied from the existing spelling, and the candidate is marked 「已在X跟踪 · 只补缺的维度」 (Already tracked in X · only the missing dimensions will be filled in) (those paused there are marked 「已在X暂停」 (Already paused in X)). When tracking starts, that existing product is added directly into this track.
- While a recommendation is running, the button becomes 「正在找…」 (Searching…) and a link to 「候选推荐」 is given.

### Moving

- **「移到」:** 「移到其他赛道…」 appears only when the product belongs to exactly one track.
  - After you choose the target track, it is done in one step: add it to the new track, then remove it from the original track.
  - The dimension cards that the new track adds are filled in right away (as when adding dimensions or tracks in M1, this waits for the daily update or profile building that is running to finish).
- **「也加到」:** it is only added into the new track, and not removed from the original.
- **「拿掉」 (Remove):**
  - Removing the last track is not allowed. The message is 「这是它唯一的赛道。不想跟了就用「暂停跟踪」。」 (This is its only track. If you do not want to follow it any more, use "Pause tracking".)
  - After a removal, the cards and history of the dimensions that only that track had are kept, they are just no longer shown.
- **Target tracks you can choose:** all tracks except those the product is already in and those that are archived. If there are none, the menu item cannot be clicked and says 「还没有别的赛道」 (No other track yet).
- **After the operation, the menu gives one line with the result:** 「已移到「〈赛道〉」」 (Moved to "<track>") or 「已加到「〈赛道〉」」 (Added to "<track>"); if cards were filled in, 「 · 补 n 张卡」 ( · n cards filled in) is added after it.

## What we are not doing

- No drag and drop: dragging a product to another track in the middle column is left for later.
- No batch moves.
- 「确认产品」 is not made into a list like 「候选推荐」.

## Left to the implementer to decide

- The layout of the add page: follow the style of the new-track page, with the class-name prefix `op-` and only dsh's color variables.
- How a track is chosen in the menu: it can be a second-level list or expand into radio buttons, but it must work with the arrow keys and Esc, and focus must return to the 「⋯」 button, consistent with how the existing menu behaves.
